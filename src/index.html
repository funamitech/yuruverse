What is YuruVerse?

One name for everything

Your Matrix ID is @you:funami.tech and your Mastodon handle is @you@funami.tech — the same domain as this page.

Hosted in Gyeonggi, South Korea

YuruVerse runs on a home server in Gyeonggi, South Korea — close to you if you are anywhere in East Asia. Only YuruMirror lives in Oracle Cloud's Seoul region.

Open source

This site, the YuruMirror theme and the Mastodon fork live on GitHub under the funamitech organization. The site itself is GPL-3.0.
