What is YuruVerse? (Yui explains)

One name for everything

Your Matrix ID is @you:funami.tech and your Mastodon handle is @you@funami.tech — the same domain as this very page. One universe, one name. Neat, right? Yui approved the naming scheme. Yui approves most things after 2 a.m.

Hosted in Gyeonggi, South Korea

YuruVerse lives on home servers in Gyeonggi, South Korea — mostly a VM named after the YuruYuri student council (Nanamori-Chu☆Seitokai, naturally), with the Oomuro sisters' little box next door holding DNS and the Matrix homeserver. Not a datacenter — a spinoff and a main series, sharing a power strip. Close to you if you're anywhere in East Asia! Only YuruMirror gets the fancy Oracle Cloud seat in Seoul. Yes, the servers are named after YuruYuri. No, Yui didn't get a vote. Yes, she's in the show.

Open source

Peek behind the curtain: this site, the YuruMirror theme and YuruYuri Glitch (our glitch-soc Mastodon fork) are all on GitHub under funamitech. The site itself is GPL-3.0, so go ahead and steal the theme (legally!). The code is GPL. Yui is not — she belongs to Namori-sensei and we're just borrowing her.
