What is YuruVerse?

One name for everything

Your Matrix ID is @you:funami.tech and your Mastodon handle is @you@funami.tech — the same domain as this very page. One universe, one name. Neat, right?

Hosted in Gyeonggi, South Korea

YuruVerse lives on a home server in Gyeonggi, South Korea — a VM named after the YuruYuri student council (Nanamori-Chu☆Seitokai, naturally), not a datacenter. Close to you if you're anywhere in East Asia! Only YuruMirror gets the fancy Oracle Cloud seat in Seoul.

Open source

Peek behind the curtain: this site, the YuruMirror theme and the Mastodon fork are all on GitHub under funamitech. The site itself is GPL-3.0, so go ahead and steal the theme (legally!).
